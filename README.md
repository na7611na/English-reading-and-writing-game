# 📚 리딩&라이팅 퀘스트 (Reading & Writing Quest)

영어 수업 시간에 **학생 개인 태블릿**으로 하는 리딩·라이팅 연습 게임입니다.
설치나 로그인 없이 웹 브라우저에서 바로 실행되는 순수 HTML/CSS/JS 웹 앱입니다.

기본으로 들어있는 표현 세트는 업로드해주신 초등 영어 교과서 **Lesson 9. I Ride a Bike (여가 시간 표현)**
파일에서 추출한 핵심 표현 20개(`What do you do in your free time?` 패턴 등)입니다.
다른 단원으로 바로 교체해서 쓸 수 있습니다.

## 게임 구성 (5종)

**📖 읽기(Reading)**
- **4지선다 스피드 퀴즈** – 우리말 뜻을 보고 알맞은 영어 표현 고르기 (오답 시 정답 발음 듣기 제공)
- **카드 매칭 게임** – 영어 카드와 뜻 카드를 짝지어 찾기 (기억력 게임)

**✏️ 쓰기(Writing)** – 순서: 문장 조립 → 스펠링 챌린지 → 받아쓰기 챌린지
- **문장 조립 게임** – 뒤섞인 단어 조각을 순서대로 눌러 문장 완성
- **스펠링 챌린지** – 우리말 뜻을 보고 **터치펜(스타일러스)이나 손가락으로 직접 손글씨**를 써서 연습
- **받아쓰기 챌린지** – 기기 음성(TTS)으로 표현을 듣고 **터치펜으로 손글씨** 받아쓰기

스펠링·받아쓰기 챌린지는 자동 채점 대신 **손글씨 캔버스**에 직접 쓴 뒤 "정답 확인"으로 정답을 보고
스스로 "✅ 정확히 썼어요 / ❌ 다시 연습할게요"로 채점하는 방식입니다. 실제 손으로 쓰는 연습에 집중할 수 있어요.

게임마다 점수·정답률이 기록되고, 틀린 표현만 모아 **"틀린 표현만 다시 풀기"** 로 복습할 수 있습니다.

## 점수 시스템

- 게임마다 **난이도별로 정답 1개당 점수가 다릅니다.** 쉬운 게임보다 어려운 게임에 도전할수록 더 빠르게 점수가 오르도록 설계했습니다.

  | 게임 | 난이도 | 정답당 점수 |
  |---|---|---|
  | 🎯 4지선다 스피드 퀴즈 | ⭐ | 10점 |
  | 🃏 카드 매칭 게임 | ⭐⭐ | 15점 |
  | 🧩 문장 조립 게임 | ⭐⭐⭐ | 20점 |
  | ✍️ 스펠링 챌린지 | ⭐⭐⭐⭐ | 25점 |
  | 🎧 받아쓰기 챌린지 | ⭐⭐⭐⭐⭐ | 30점 |

  게임 선택 화면에도 난이도(⭐)와 정답당 점수가 표시되어, 같은 시간을 연습해도 어려운 게임을 하면 총점이 더 많이 오른다는 것을 학생들이 바로 알 수 있습니다.
- 게임을 마칠 때마다 **게임별 누적 점수**와 **총점**이 바로 갱신되어 결과 화면·홈 화면·학습 기록 화면, 그리고 화면 우측에 항상 떠 있는 총점 배지에 표시됩니다.
- 점수는 계속 쌓이는 방식이라, **틀린 문제를 "틀린 표현만 다시 풀기"로 다시 풀어 맞히면 그만큼 총점이 올라갑니다.**
- 모든 기록은 학생 이름별로 해당 태블릿(브라우저)에 저장됩니다. (다른 기기와 실시간으로 공유되는 반 전체 랭킹 기능은 없습니다 — 외부 서버 연동이 필요해 이번 버전에는 포함하지 않았습니다.)

## 교사용: 표현 목록 관리

홈 화면 → **"📋 표현 목록 관리"** 에서:
- 단원(세트)별로 표현을 나눠 관리 (여러 단원 저장 가능, 드롭다운으로 전환)
- `영어 표현 = 한국어 뜻` 형식으로 여러 줄을 한 번에 붙여넣기 가능
- 표현 4개 이상부터 게임 플레이 가능
- "샘플 데이터로 초기화"로 언제든 기본 Lesson 9 세트로 되돌릴 수 있음

> 데이터는 각 태블릿의 브라우저(localStorage)에 저장됩니다. 학급 전체에 같은 표현 세트를 쓰려면,
> 교사 태블릿에서 세트를 만든 뒤 같은 텍스트를 각 학생 태블릿의 "빠른 붙여넣기 가져오기"에 붙여넣어 배포하세요.

## 실행 방법

### 1) 그냥 열기
`index.html` 파일을 태블릿 브라우저(Chrome, Safari 등)로 열면 바로 실행됩니다. (인터넷 연결 불필요,
단 발음 듣기 기능은 기기에 내장된 TTS 엔진을 사용합니다.)

### 2) GitHub Pages로 배포해서 링크 공유 (권장)
1. 저장소 Settings → Pages → Source를 `main` 브랜치, `/ (root)` 로 설정
2. 몇 분 뒤 `https://<사용자명>.github.io/<저장소명>/` 주소가 생성됨
3. 학생들에게 이 주소를 QR코드나 링크로 공유 → 태블릿 브라우저에서 바로 접속

## 파일 구조

```
index.html          메인 화면 구조 (홈/설정/게임 선택/플레이/결과/기록)
css/style.css        전체 디자인 (태블릿 터치에 맞춘 큰 버튼, 반응형)
js/data.js           표현 데이터·점수 저장/불러오기, 기본 Lesson 9 세트
js/speech.js         영어 발음 듣기 (Web Speech API)
js/utils.js          공용 유틸 함수
js/handwriting.js    터치펜 손글씨 캔버스 (Pointer Events)
js/games.js          5가지 미니게임 로직
js/app.js            화면 전환, 교사용 편집기, 결과/기록/점수 화면
```
